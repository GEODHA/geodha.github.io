# Blog & CMS

The blog at `/blog` is built from Markdown files in [`content/blog`](../content/blog).
They are bundled at build time (`src/lib/blog.ts`) — no server, embed or API key.

## Writing a post

**Option A — pull request.** Add `content/blog/YYYY-MM-DD-your-slug.md`:

```md
---
title: "Post title"
date: 2026-10-01
author: "Your name"
summary: "One or two sentences for the blog index."
cover: /media/blog/your-image.jpg   # optional, put the file in public/media/blog
tags: [waste, wards]
draft: false                         # true hides it from the site
---

Body in Markdown…
```

The URL is `/blog/<file name without .md>`.

**Option B — Decap CMS at `/cms/`.** Log in with GitHub (needs write access to the
repo). `publish_mode: editorial_workflow` is on, so each draft becomes a pull
request; clicking **Publish** merges it to `main`, which redeploys the site.

## One-time setup: GitHub OAuth for Decap

GitHub Pages can't do the OAuth token exchange, so Decap needs a tiny proxy:

1. Create a GitHub OAuth App (GitHub → Settings → Developer settings → OAuth Apps).
   Homepage `https://geodha.org`, callback `https://<your-proxy>/callback`.
2. Deploy an OAuth proxy, e.g. [sterlingwes/decap-proxy](https://github.com/sterlingwes/decap-proxy)
   on Cloudflare Workers (free tier), with the app's client ID/secret as secrets.
3. In [`public/cms/config.yml`](../public/cms/config.yml) uncomment `base_url` and set it
   to your proxy URL. Commit — `/cms/` login now works.

Local editing without OAuth: run `npx decap-server` and `npm run dev`, then open
`http://localhost:8080/cms/` (`local_backend: true` is enabled).

> `/admin` is the Firebase admin panel; the blog editor deliberately lives at `/cms`.

## Ward data for the Neighbourhood Scorecard

`src/data/gba-wards.json` and `public/data/gba-369-wards.geojson` are generated by
`scripts/build-gba-wards.mjs` from the GBA 369-ward delimitation (Dec 2025, OpenCity;
GeoJSON conversion by kaun-city/kaun, MIT). Re-run it if boundaries change:

```sh
node scripts/build-gba-wards.mjs path/to/bengaluru-gba-369.geojson
```

Corporation contacts live in `src/data/gbaContacts.ts` — update them when officials change.
